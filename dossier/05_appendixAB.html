Method notes

  • Emoji scan class: U+1F000 to U+1FAFF, U+2600 to U+27BF, U+2B00 to U+2BFF, U+2190 to U+21FF, with optional U+FE0F. v1's lower count likely came from a narrower class or from text extracted from the PDF, where the 6 pt code font drops emoji glyphs (the PDF-derived reconstruction finds only 16). The acceptance test in the pre-flight script is zero glyphs in the whole file, so the class is deliberately wide.
  • Contrast: WCAG 2.x relative luminance, sRGB, ratio (L1 + 0.05) ÷ (L2 + 0.05). "Derived" values in Part 2 use the same formula on token pairs not directly in v1.
  • DNS: getent ahosts from the build container; HTTP probing to the candidate domains is blocked by the egress proxy, so hosting could not be inspected.
  • What could not be verified: the Gamma deck contents, the Drive documents, Laundry Lady's 2026 per-load price and whether their minimum includes delivery, and the v1 real-device screenshots (accepted as stated). The mobile menu count was verified in the fact-check pass (Appendix D).
